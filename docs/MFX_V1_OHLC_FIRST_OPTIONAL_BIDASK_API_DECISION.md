## Two noninterchangeable lanes

**Lane A — OHLC-FIRST RESEARCH/ENGINEERING, NOT actionable market advice.** Develop closed-candle multi-timeframe trend/zone/event detectors, causal as-of joins, quality/freshness/source SHA checks and candidate state/reason logic using SIM inputs or separately permitted OHLC. This algorithmic research does **not** mathematically require BID/ASK or any broker terminal. A current MID-only bar or archived cache still does not prove source subscription legality, original strategy numeric rule signoff, publisher first-known or live freshness. Synthetic internal BUY/SELL candidate hints are never certified original 1:1 signals. Source owner B2/S2 0/36 and 14 other entry strategies remain unapproved.

**Lane B — BID/ASK + COST AWARE OUTPUT, OPTIONAL DEPENDENCY BEFORE VERIFIED ECONOMICS.** When independently reviewed terms support the account/product, use a read-only API delivering instrument-labelled, event-time/first-known aware quote-side data with acknowledged spread characteristics and lawful retention/replay. LONG references ASK entry and BID exits; SHORT references BID entry and ASK exits. Side-aware net-R:R also needs a separately approved stop/target, fee, slippage, timing and adverse-cost policy. Historical BID/ASK *candle aggregates* or indicative composite quotes are **not guaranteed broker tick quotes or actual fills**. The existing P0.151/P0.152 SIM cost calculations are research-only, never substitute for such evidence.

**MT4/MT5 terminal policy:** **not required** for either MFX baseline OHLC research or its proposed future API-first BID/ASK source. A separately approved broker-specific terminal is an optional future architecture, not a requirement and not selected by this decision. The user requested signal-only outputs: no order placement, terminal installation, broker-account integration or trading secrets.
