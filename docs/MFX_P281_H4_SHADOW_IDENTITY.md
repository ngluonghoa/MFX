# P281 — canonical H4 shadow identity and value validation

Follow-up to P280 independent native-grid validation. P065 shadow comparator accepted alternate ISO spellings of the same UTC start, compared their raw strings for uniqueness, and could count the same native window twice. It also accepted nonhex 64-character input fingerprints and invalid derived OHLC as ordinary comparisons. Require canonical generated UTC start identity, exact lowercase hexadecimal fingerprint shape and finite positive decimal-text OHLC with valid bounds. Six regression methods cover equivalent start spellings, duplicate matching, exact canonical duplicate rejection, malformed hashes, invalid ranges and nontext values. Existing valid generated windows, MATCH/MISMATCH/MISSING semantics, and false source/release authority remain unchanged. Fingerprint shape is not proof of origin or recomputation from source bars.
