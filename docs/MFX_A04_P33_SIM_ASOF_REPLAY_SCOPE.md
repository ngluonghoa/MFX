# A04/P0.33 — Chronological CLOSED-SIM OHLC replay and hash-linked research evidence

**Status: MFX research infrastructure, NOT a source-approved Forex backtest or executable BUY/SELL.** This milestone builds on the actual P0.32 OHLC-computed, experimental B2/S2 models and the P0.31 approved-design 22-zone NO_SIGNAL router. All work stays on GitHub Actions / Google Drive, with no Mac/MOCHI/local runtime and no edits to frozen Forex `src/`.

## What P0.33 now computes
- Replay a bounded immutable sequence of independently computed `SyntheticReplayWindow` snapshots; each contains CLOSED synthetic D1/H4/H1/M15 OHLC, explicitly versioned **owner-unapproved experimental** derivation/trigger parameters, a B2 or S2 pilot name, and a strictly increasing UTC decision clock.
- Every snapshot invokes **P0.32** (P0.19 causal context computation, P0.18 experimental numeric pattern and P0.31 role routing). This is *actual calculation on simulated prices*, not a user-asserted label; however P0.32's mathematical choices **are not sourced/owner-approved 1:1 Forex numerical rules**.
- Accept a window only when all price series are synthetic, complete, closed, as-of known/retrieved, with exact source calendar/side/stream consistency, no hidden revision or future-known bar. If a computed pattern is absent, record the **NO_SIGNAL snapshot with zero labels/groups** rather than fabricating a candidate.
- Reject duplicate originating M15 source events **even if** their prices, pilot rule or decision time have changed. Later events with new source timestamps can be appended; events must have monotonically increasing decision times.
- Compute a canonical SHA256 payload from each research receipt (origin, first-known, full-fixture P0.32 SHA256, computed experimental BUY/SELL or no pattern, ATR context, role labels, NO_SIGNAL), then link `chain[N] = SHA256(chain[N-1] bytes + payload[N] digest bytes)`, with a fixed versioned genesis digest.
- Verify full chain, source gates and counts with `verify_sim_replay_chain`. The **causal-prefix invariant** means replaying the same earlier OHLC and appending a later independent snapshot cannot alter any earlier evidence record or its chain hash. Tampering with an in-memory receipt or original event gets rejected.

## Deliberately not implied
This is a **deterministic, in-memory, synthetic replay**, not recorded real-world OOS performance, backtest P&L, forward simulation with operational latencies, cryptographically signed audit storage, durable distributed event-dedup/anti-rollback, verified independent market vendor quotes, actual position exit or live signal. A SHA hash is a local reproducibility fingerprint, not a source attestation. The no-pattern and conflicting claims safety layers prevent accidental promotion to a trade recommendation; action stays **NO_SIGNAL** even when the experimental action says BUY/SELL for fixture testing.

There are **22 MFX-approved DESIGN labels (8 BUY entry candidates, 8 SELL entry candidates, 2 WATCH, 4 protective), not 22 independently computed numeric detectors**. Only B2/S2 experimental SIM patterns are computed along this chain. The original frozen Forex catalog remains 18, previous MFX 19-label snapshot is historical, P0.30 current effective 22-label design is untouched.
