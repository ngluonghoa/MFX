## Simulated protocol

1. Canonical immutable identity: `SIM:` instrument, B2/S2, SIM policy, origin, provider/stream/calendar/aggregation versions, candle close, first-known, retrieved clocks and MID side; validation forbids OHLC payload, real vendor IDs, source-numeric-approval claim, BID/ASK or forged production licensing.
2. First seen SIM event can be `RESEARCH_JOURNALED` only with explicit mock metadata-review flag and after retrieval; event TTL, at-most-32 journal records and 128 append-only transitions are enforced. Duplicate event ID remains tombstoned even after TTL expiry. An UNREVIEWED/REVOKED flag denies writes, and a reviewed simulation does **not** confer real Drive write permission.
3. Immutable snapshots carry contiguous revision, per-record canonical state SHA and a linked per-entry SHA-256 digest. Tampered hash or swapped snapshot state fails validation; note that **checksums are not trusted signatures**. Separate `TrustedMockCheckpoint(revision,digest)` is required to reject restoration of an older valid snapshot. Real trusted highwater escrow is not implemented.
4. `MockCloudCASStore.cas` models conditional expected-revision+head-hash append in one in-memory process; two snapshots from the same revision cannot both commit. This does **not** establish Google Drive revision atomic CAS support; concurrency/consistency must be verified for any future actual Cloud API connector and storage schema before writes.
5. Lease claims use monotonic fence epochs and SIM worker IDs; claim race accepts one CAS, stale worker cannot release or mark attempt after takeover. A recorded attempt changes to `DELIVERY_AMBIGUOUS_SIM`; on crash/restart the record remains ambiguous and auto retry is refused. There is **no external notification provider/receiver/ack**. Exactly-once user-visible delivery cannot be asserted without receiver-side idempotency and acknowledgement.
6. Mock restart is reinitialization with a copy of previous snapshot + separately supplied mock checkpoint; it proves deterministic replay of supplied state, **not durability of any actual storage**. No actual Drive journal or raw Forex price write ever occurs. Compaction, schema migration, garbage collection and production alerts are deliberately blocked pending independent review.
